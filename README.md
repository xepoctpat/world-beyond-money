# H3X — A Manifesto / Manifest

A movement-launching one-page site for the H3X Manifesto. Bilingual (Serbian / English). Public domain. Free to fork.

> **No copyright. No permission. No end.**
> Reproduce it. Multiply it. Set it loose.

## Hosting (free, ~20 minutes)

1. Make a GitHub account at https://github.com (free, no card).
2. Create a public repo named `world-beyond-money`.
3. Upload `index.html`, `README.md`, and the `downloads/` folder.
4. Settings → Pages → Source: Deploy from a branch, Branch: main, Folder: / (root). Save.
5. Visit `https://YOURNAME.github.io/world-beyond-money/`.

## Sign the manifesto (Tally form)

1. https://tally.so → free account.
2. Create a form: full name, email (optional), city/country (optional), public-list opt-in.
3. Share → Embed → copy form ID.
4. In `index.html`, replace `REPLACE_ME` (one occurrence, in the iframe `src`) with your Tally form ID.
